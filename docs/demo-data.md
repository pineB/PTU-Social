# Демо-данные

Загружаются автоматически в профиле `dev`: `DevDataSeeder` (база) → `DevDemoDataSeeder` (`@Order(2)`).
Повторный запуск ничего не дублирует: сидер выходит, если у `student@ptu.local` есть предметы с источником `Демо-набор`.
Загрузка идёт только при пустой базе или после `docker compose down -v` (пересоздание тома Postgres).

## Что загружается

- 8 групп: ИС-21, ИС-22, ИС-23, ПИ-21, ПИ-22, ЭК-21, ЭК-22, БД-21 — по 6 студентов, старосты.
- Рейтинги 20…1250, кошельки 300…5000 жетонов, история транзакций.
- 7 тематических кейсов: первокурсника (100), программиста (150), дизайнера (150), старосты (200), сессии (250), выпускника (300), киберспорта (180) — у каждого 5–6 наград, покрыты все типы косметики и редкости, картинки-заглушки в БД.
- ПТУ-пасс: 50 уровней × 2 дорожки (free — кейсы, premium — косметика), у основного студента забраны уровни free ≤ 12 и premium ≤ 6.
- 9 заданий с дедлайнами и 13 решений в статусах `ACCEPTED` / `RETURNED` / `SUBMITTED`.
- Расписание на 6 групп + 2 изменения расписания.
- 7 мероприятий (индивидуальные и групповые), регистрации групп, участия, 10 одобренных отзывов (рейтинг 4.5), отзывы на модерации (в т.ч. с нецензурным словом).
- 8 заявок на справки во всех статусах (одна с PDF), 2 заявки на вступление в группу.

## Проверка

```bash
docker compose up -d --build
# студент
curl -s -X POST localhost/api/auth/login -H 'Content-Type: application/json' \
  -d '{"email":"student@ptu.local","password":"demo12345"}'
```

Фронт: `http://localhost` — пасс, инвентарь (открытие кейса), мероприятия, задания; `http://localhost:8025` — Mailpit.
