## Уточнение переключения темы и контрастности

### Запрос

> Кнопки переключаются не одновременно со сменой темы; текущая выбранная вкладка и статусы в заданиях слишком бросаются в глаза при переключении.

### Выполненная работа

- Тема MUI теперь использует постоянный объект с CSS-переменными обеих палитр. Переключение цветовой схемы и состояния кнопки выполняется через единый API `useColorScheme`, без повторного создания темы на каждый клик.
- MUI отключает переходы компонентов во время смены режима, устраняя рассинхронизацию между обновлением цветовой схемы и переключателем.
- Снизил контраст активного раздела: нейтральная подложка вместо яркого фиолетового фона, тонкий индикатор и простые иконки вместо цветных буквенных плашек.
- Статусы заданий используют мягкий цветовой фон и менее насыщенный текст; удалён источник более ярких стандартных цветов MUI Chip.
- В обработчике переключения атрибут цветовой схемы устанавливается до обновления React-состояния; обе палитры MUI задаются CSS-переменными без пересоздания темы. Переход на выбранный режим сразу меняет цвета фона и иконку переключателя.
- Дополнительно уменьшена насыщенность статусов «успешно» и «срочно».
- У выбранной вкладки отключён переход цвета фона: он продолжал показывать цвет предыдущей темы в течение CSS-анимации, хотя новая тема уже включилась.

### Проверка

- Production-сборка и проверка типов: `npm run build` — успешно; Vite сохраняет предупреждение о размере JS-бандла более 500 kB.
- Проверка переключения в браузере подтвердила синхронное изменение атрибута темы, цвета активного пункта и статусов, иконки и доступного названия переключателя.
- `git diff --check` — ошибок форматирования не обнаружено.
