- Создатель указывает тип активности (БОА/БУА) и максимум награды. После окончания он подтверждает фактическое участие; каждому участнику разрешено назначить целое значение от 0 до 100, не выше максимума мероприятия, с соблюдением бюджета. Повторное начисление запрещено.

- Валюта поступает из ежемесячной конвертации БОА/БУА и награды за одобренный отзыв; АР не конвертируется. Кейсы выдаются уровнями, прямой покупки случайных кейсов нет. Инвентарь хранит кейсы и предметы.
